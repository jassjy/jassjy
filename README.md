## Sobre mí

Soy aprendiz del **Tecnólogo en Análisis y Desarrollo de Software (ADSO) del SENA**, interesada en el desarrollo de aplicaciones, la programación y la construcción de soluciones tecnológicas.

Me encuentro fortaleciendo mis conocimientos en desarrollo backend, bases de datos, consumo y creación de API REST, operaciones CRUD y pruebas de software. Me gusta aprender mediante proyectos prácticos, resolver problemas y mejorar continuamente mis habilidades técnicas.

- Formación tecnológica en el SENA.
- Conocimientos en JavaScript, Python y SQL.

- Experiencia académica con bases de datos relacionales y no relacionales.
- Uso de Git, GitHub, Visual Studio Code y Postman.

## Proyectos destacados

### 1. Huellitas Saludables

**Sistema web para la gestión integral de servicios para mascotas.**

Proyecto enfocado en una solución digital para conectar servicios veterinarios y de cuidado de mascotas, facilitando la organización de la información y la gestión de servicios.

**Enfoque técnico:** desarrollo web, API REST, bases de datos y gestión de información.

[Ver repositorio de Huellitas Saludables](https://github.com/jassjy/HUELLITAS_SALUDABLES_PROYECTO)

---

### 2. Quality Orders — Sistema de gestión de pedidos

Proyecto académico orientado a la gestión de pedidos y al desarrollo de una solución de software para organizar información relacionada con este proceso.

**Enfoque:** análisis de requerimientos, desarrollo de funcionalidades y organización de datos.

[Ver repositorio de Quality Orders](https://github.com/jassjy/Sara-Jasmin-Cruz-Calderon-3407180-Quality-Orders---Sistema-de-gestion-de-pedidos)

---

### 3. Proyecto Clientes

Proyecto de práctica relacionado con la gestión de información de clientes, como parte del aprendizaje de desarrollo de aplicaciones y manejo de datos.

**Enfoque:** organización de información y desarrollo de funcionalidades para su administración.

[Ver repositorio Proyecto Clientes](https://github.com/jassjy/PROYECTO-CLIENTES)

---

### 4. Proyecto CRUD 80 — API REST

Proyecto práctico enfocado en el desarrollo backend y el aprendizaje de operaciones CRUD para la gestión de productos.

**Operaciones CRUD:**
- **Create:** crear registros.
- **Read:** consultar registros.
- **Update:** actualizar información.
- **Delete:** eliminar registros.

**Enfoque técnico:** JavaScript, Node.js, Express y organización de rutas, controladores y modelos.

[Ver repositorio Proyecto CRUD 80](https://github.com/jassjy/Sara-Jasmin-Cruz-Calderon-3407180-proyectoCrud80)
