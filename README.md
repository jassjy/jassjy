## Sobre mí

Soy **Técnica en Programación de Software y aprendiz del Tecnólogo en Análisis y Desarrollo de Software (ADSO) del SENA**. Me interesa el desarrollo de aplicaciones, la programación backend, la administración de bases de datos y la calidad del software.

A través de mi formación académica y mis proyectos, estoy fortaleciendo mis competencias para analizar requerimientos, desarrollar funcionalidades, gestionar información y construir soluciones tecnológicas.

Me caracterizo por mi interés en el aprendizaje continuo, la resolución de problemas y la aplicación práctica de los conocimientos adquiridos.

- Formación técnica en programación de software.
- Formación tecnológica en análisis y desarrollo de software.
- Conocimientos en JavaScript, Python y SQL.
- Práctica en desarrollo backend y API REST.
- Fundamentos de bases de datos relacionales y no relacionales.
- Manejo de Git, GitHub, Visual Studio Code y Postman.
- Formación complementaria en desarrollo web y ciencia de datos.

## Proyectos destacados

### 01. Huellitas Saludables

**Sistema web para la gestión integral de servicios para mascotas.**

Proyecto enfocado en la gestión de servicios veterinarios y de cuidado de mascotas, con el propósito de facilitar la organización de información y la administración de servicios.

**Áreas del proyecto:**
- Gestión de información relacionada con propietarios y mascotas.
- Organización de servicios veterinarios y citas.
- Gestión de información clínica y servicios de cuidado.

**Tecnologías previstas:** JavaScript, React, Node.js, API REST y PostgreSQL.

[Ver repositorio](https://github.com/jassjy/HUELLITAS_SALUDABLES_PROYECTO)

---

### 02. Quality Orders — Sistema de gestión de pedidos

Proyecto académico orientado a la gestión de pedidos y al desarrollo de una solución de software para organizar información relacionada con este proceso.

**Enfoque:**
- Análisis de requerimientos.
- Organización y gestión de datos.
- Desarrollo y validación de funcionalidades según los requerimientos del sistema.

[Ver repositorio](https://github.com/jassjy/Sara-Jasmin-Cruz-Calderon-3407180-Quality-Orders---Sistema-de-gestion-de-pedidos)

### 03. Proyecto Clientes

Proyecto de desarrollo enfocado en la gestión de información de clientes y la práctica de conceptos de programación y administración de datos.

**Enfoque:**

### 04. Proyecto CRUD 80 — API REST

Proyecto práctico de desarrollo backend orientado a la gestión de productos mediante operaciones CRUD.

**Operaciones principales:**
- **Create:** creación de registros.
- **Read:** consulta de información.
- **Update:** actualización de registros.
- **Delete:** eliminación de registros.

**Tecnologías de práctica:** JavaScript, Node.js y Express.

[Ver repositorio](https://github.com/jassjy/Sara-Jasmin-Cruz-Calderon-3407180-proyectoCrud80)
